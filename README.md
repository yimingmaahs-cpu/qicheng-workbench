# 毛毡伙伴 ·《燕云十六声》AI 桌宠

以《燕云十六声》角色为灵感制作的非官方 Windows 三维桌宠同人项目。当前公开版本为 **0.1.8**，内置比格形象的少东家「烧冬瓜」和垂耳兔形象的「陈慎」。

## 下载与使用

前往 [桌宠 0.1.8 下载页](https://github.com/yimingmaahs-cpu/qicheng-workbench/releases/tag/yanyun-v0.1.8)，下载 `Felt-Companions-0.1.8-x64-Setup.exe`。适用于 Windows x64，安装后从桌面快捷方式启动。更新安装前，请先从系统托盘退出旧版毛毡伙伴。

本项目位于仓库的 `yanyun-desktop-pet` 独立分支。桌宠使用 `yanyun-v0.1.8` 标签，下载请使用上面的专属链接。仓库默认分支和“最新版本”用于启程求职工作台。

## 功能

- 切换两个三维角色，支持拖动、散步、鼠标关注及动作回应。
- 双击桌宠展开输入框，在角色头顶的独立气泡查看回复。
- AI 文字对话支持流式回复、角色上下文、修改最后一轮、重新回答和继续回复。
- 自动整理长期记忆，可查看、编辑、删除和导出本地聊天与记忆。
- 日历、待办、重复提醒、番茄钟、专注记录和离线角色语录。

0.1.8 是文字陪伴发布版。语音交流、游戏画面识别与自动陪玩属于后续实验预览功能。

## 配置自己的模型服务

首次使用，在「聊天 → 模型与用量」填写自己的模型服务地址和 API Key。默认模型名为 `qwen-plus-character`（角色对话）和 `qwen-plus`（记忆整理），请确认所用服务支持对应模型。

**每位使用者自行配置模型账户并承担调用费用。发布包初始没有 API Key、聊天记录、用户人设或记忆，也没有作者提供的共享模型额度。** 没有配置模型时，可以使用桌宠互动、日程和离线语录。配置后的对话与自动记忆整理均可能产生模型调用费用。

聊天与记忆保存在本机。调用模型时，相关对话、角色资料和记忆会发送到用户配置的模型服务。API Key 使用 Electron 的系统加密能力保存到用户自己的数据目录。分享给朋友时，请转发本发布页中的原始安装包。

## 从源码运行

本分支从封存的 0.1.8 源码导出，包含应用源码、构建配置和运行素材。开发环境使用 Node.js 24。

```powershell
git clone --branch yanyun-desktop-pet --single-branch https://github.com/yimingmaahs-cpu/qicheng-workbench.git
cd qicheng-workbench
npm ci
npm start
```

`npm run build` 检查类型并构建应用。`npm run package` 生成 Windows x64 安装包。
